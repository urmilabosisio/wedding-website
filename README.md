# Wedding Website — Personal Web Development Project

A responsive website created for a personal event and deployed with Vercel.

**Live website:** [teoeurmi.com](https://teoeurmi.com)

## Overview

This project brings together event information and a personalized, mobile-friendly web experience. It is an example of translating real requirements into a website with a consistent visual identity.

## Features

- Event information and responsive page layout
- Personalized visual styling
- Story and photo sections
- Interactive elements and guest-facing content

*Features depend on the version of the website included in this repository.*

## Technologies

- HTML
- CSS
- JavaScript
- Git / GitHub
- Vercel (deployment)

## Running locally

Open `index.html` in a web browser. If your version uses a build process or server-side functionality, follow its own setup instructions instead.

## Privacy

This is a personal project. Before publishing the repository, remove private guest information, personal messages, credentials, private RSVP data and photos that should not be shared publicly.

## What I learned

- Building a website around real user requirements
- Responsive layout and UI details
- Iterative development and deployment
- Using version control to document changes
